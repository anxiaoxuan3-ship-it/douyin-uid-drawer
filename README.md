# 抖音 UID 抽号器

给「随机 UID 看号」主播用的直播抽号工具。从抖音直播间公屏自动收集观众 UID，
公平抽取中奖者，并用一个**绿幕窗口**把结果展示给观众 —— 直播伴侣加一路
「窗口捕获 + 绿幕抠图」就能用。

**纯 Python 标准库实现，零第三方依赖**（界面用 tkinter，抽取用 `secrets` + `hashlib`）。

> 📷 界面截图见 `截图/` 目录。

## 它解决什么问题

抖音会屏蔽公屏上的纯数字 UID，观众为了把号码发出来，会写成各种花样：

| 观众发的 | 本程序还原成 |
|---|---|
| `100 591 822` | `100591822` |
| `100.591.822` | `100591822` |
| `100-591-822` | `100591822` |
| `UID:100591822` | `100591822` |
| `1oo591822`（字母 o 冒充 0） | `100591822` |
| `１００５９１８２２`（全角） | `100591822` |
| `100\n591\n822`（换行） | `100591822` |
| `一〇〇五九一八二二`（中文数字） | `100591822` |

同时要避开一堆**看起来像但不是**的数字：`666`、`888`、`2024`、`12345`、
「第3轮」「抽2个」这类聊天内容。识别引擎专门处理这件事。

## 功能

**抽取**

- 参与者池实时去重，同一个人刷屏只算一次
- 公平抽取，**结果可被任何人复算验证**（见下文）
- 滚动动画 + 定格，展示窗上直接给观众看
- 中奖记录、撤销上一次、已中奖不再参与、按发言次数加权
- 参与池可导入导出、拉黑

**展示（给直播伴侣抓）**

- **绿幕显示窗**：默认 `#00AA00` 纯色背景，直播伴侣「窗口捕获 + 绿幕抠图」直接抠掉
- **参与名单窗**：独立窗口，把参与池里的 UID 分页铺开给观众看谁参与了；
  有人刚加入会自动跳到最后并高亮他
- 背景模式可选：纯色（绿幕/蓝幕/品红）、真透明（`-transparentcolor`）、图片
- 自定义字体/字号/颜色/**描边粗细**（描边够粗才压得住任何直播画面）
- 界面里自带**采集体检**：一键检测窗口能不能被采集软件列到、抓到的画面是不是黑屏

**弹幕来源**

- **抖音直连**：开一个真实浏览器旁听公屏 WebSocket，不用登录、不用签名算法
- **HTTP 推送**：任何能发 HTTP 请求的东西都能推弹幕
- **弹幕文件**：追加写入的文本文件（配合 OBS 弹幕插件、日志转发等）
- **剪贴板**：适合手动粘贴测试
- **演示模式**：没有真实弹幕时用来试机

## 快速开始

### 普通用户

1. 到 [Releases](../../releases) 下载 `UID抽号器.exe`
2. 双击运行。三个窗口会出现：**控制台**、**展示窗**、**参与名单窗**
3. 直播伴侣 → 添加素材 → 窗口捕获 → 选 `★ UID 抽号展示窗口 ★`
4. 打开「绿幕抠图」→ 吸管点一下窗口的绿色底 → 调相似度
5. 按 `F1` 抽号

**快捷键**

| 键 | 作用 |
|---|---|
| `F1` | 开始抽取 |
| `F2` | 撤销上一次中奖 |
| `F3` | 显示 / 隐藏展示窗 |
| `F4` | 最小化控制台 |
| `F5` | 显示 / 隐藏参与名单窗 |

> 详细用法、常见问题、识别参数怎么调，见 **[使用说明.md](使用说明.md)**。

## 识别引擎（抗屏蔽）

核心在 [`uidkit/normalize.py`](uidkit/normalize.py)。流程：

```
原始弹幕
  → NFKC 规范化（全角→半角、各种奇怪空格→普通空格）
  → 逐字符分类：数字 / 软分隔符 / 硬分隔符
  → 把被软分隔符切碎的数字段合并回来（允许最多 N 个分隔符）
  → 标签剥离（UID: / 抖音号 / 编号…，替换成等长空格以免打乱下标）
  → 字母混淆修正（o→0、l→1、S→5…）
  → 打分选优（长度、位置、上下文关键词）
  → 输出 UID
```

三种模式：

| 模式 | 行为 | 适合 |
|---|---|---|
| `strict` | 只认整条弹幕就是号码的 | 最大程度防误判 |
| `smart`（默认） | 整条是号码、或带明确标签的，都认 | 大多数直播间 |
| `loose` | 号码出现在句子中间也认 | 观众写法很随意时 |

可调项：最短/最长位数、允许的分隔符数量、中文数字、字母混淆修正、
必须包含/禁止包含的关键词、常见数字黑名单（`666`/`888`/`520` 之类）。

**标签剥离必须发生在字母修正之前** —— 否则 `UID:100591822` 会被修成
`10100591822`。这个坑在代码里有注释标着。

## 抽取是怎么保证公平的

主播抽号最怕被质疑「你是不是内定了」。所以每次抽取都留下可复算的证据：

```
seed        = secrets.token_hex(8)        # 系统级随机源，不可预测
fingerprint = sha256(参与池内容)[:8]       # 抽奖那一刻池子的指纹
rng         = random.Random(f"{seed}|{fingerprint}")
```

然后对池子做 Fisher–Yates 部分洗牌取出中奖者。

抽取后界面会显示一行**可发到公屏的凭证**：

```
第1轮 参与40人 种子F41D182DF333F70D 指纹3F65C537 结果[100590003,100590022]
```

任何人拿到 `种子 + 指纹 + 参与池快照`，都能用同样的算法复算出同样的结果 ——
`uidkit/draw.py` 里的 `verify()` 就是干这个的。种子来自 `secrets`，
不是 `random` 的默认种子，事先无法预测。

## 抖音弹幕直连

[`tools/抖音弹幕直连/`](tools/抖音弹幕直连/) 是一个独立的旁听工具：

- 用**真实 Chrome/Edge** 打开直播间页面（不是无头浏览器）
- 通过 **CDP（Chrome DevTools Protocol）** 挂在 `Network.webSocketFrameReceived` 上
- 自己手写 protobuf 变长整数解析 + 纯标准库的 WebSocket 客户端，解析弹幕帧
- 把识别出的文本 POST 给抽号器的 HTTP 接口

**不用登录、不用逆向签名算法**，因为它就是让浏览器正常播一个直播间，
我们在旁边听。

```bash
python tools/抖音弹幕直连/douyin_bridge.py https://live.douyin.com/<房间号>
```

关于自动化特征：网页检测自动化最常用的信号 `navigator.webdriver`，
实测在「只开远程调试端口」「挂上 CDP」两种情况下**都是 `false`**
（Chrome 只在 `--enable-automation` 时才置 `true`，那是 Selenium 的做法）。

> ⚠️ **技术上的自动化特征和平台规则是两件事。** 这个工具处于抖音用户协议的
> 灰色地带，请自行评估风险。详见
> [抖音直连说明](tools/抖音弹幕直连/说明.md) 里的《会不会被抖音风控》一节。

## HTTP 推送接口

抽号器内置一个小 HTTP 服务（默认 `127.0.0.1:8787`），任何工具都能往里推弹幕。

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/push?text=...&nick=...` | 推一条弹幕，返回识别结果 |
| `POST` | `/draw?count=1` | 抽号 |
| `GET` | `/status` | 当前状态（人数、轮次、中奖名单…） |
| `POST` | `/reset` | 清空参与池 |
| `GET` | `/` | 网页版接口面板（可以在浏览器里手动推、手动抽） |
| `GET` | `/overlay` | 浏览器版叠加页（OBS 浏览器源可用） |

- **本机（127.0.0.1）访问一律放行**，不需要 token。
- 只有从**别的设备**（手机、另一台电脑）访问时才需要带 `?token=xxx`。
  这是为了挡住局域网里别人乱推 —— 本机程序本来就能读到配置里的 token，
  对本机设防没有实际意义。

## 自己打包成 exe

```bash
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name "UID抽号器" \
  --icon assets/app.ico --hidden-import tkinter --hidden-import tkinter.ttk \
  main.py
```

Windows 上也可以直接双击 `打包成exe.bat`。

> **别把 exe 放在受系统管控的目录里。** 单文件 exe 每次启动都要先把自己解压到
> `%TEMP%`；如果所在文件夹被加了完整性级别之类的限制，解压会失败，
> 而纯窗口程序这时是**完全静默**的 —— 表现就是「双击没反应」。
> 真遇到的话，双击 `启动UID抽号器（推荐）.bat`（它把临时目录改到程序旁边）。

## 项目结构

```
main.py                    程序入口：拼装各部件、启动数据源、安排窗口位置
uidkit/
  normalize.py             ★ 识别引擎（抗屏蔽的核心）
  draw.py                  公平抽取 + 结果复算验证
  state.py                 Session：喂弹幕、抽取、快照
  pool.py                  参与者池（去重、导入导出、持久化）
  console.py               控制台界面（tkinter，1800+ 行）
  overlay.py               展示窗（绿幕 / 透明 / 图片背景，无边框可拖动）
  board.py                 参与名单窗（分页展示，新加入高亮）
  layout.py                三个窗口的位置安排（避免重叠、跑出屏幕）
  netserver.py             内置 HTTP 服务 + 网页接口面板
  web.py                   接口面板 / 浏览器叠加页的 HTML
  sources.py               弹幕来源：文件 / 剪贴板 / 演示 / HTTP
  winutil.py               Windows 窗口样式（让采集软件能列到窗口）
  config.py                配置读写
  bus.py                   线程安全事件总线
tests/
  test_normalize.py        识别引擎 32 项测试
tools/
  抖音弹幕直连/             浏览器 + CDP 旁听公屏
    douyin_bridge.py       主程序
    douyin_pb.py           手写 protobuf 解析
    wsclient.py            纯标准库 WebSocket 客户端
assets/                    图标
截图/                      界面截图
使用说明.md                 给用户看的完整说明
```

规模：主程序约 7400 行，抖音直连约 1100 行。
